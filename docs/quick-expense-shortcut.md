# Apple Shortcut automatic expense saving

Settings → General → Quick Expense offers the signed public preset and an account-specific connection. Choose a preferred wallet, authorize your currently active synced wallets, create the connection, and paste its one-time key into the preset's import question. Then assign Finance Tracker Quick Expense in iPhone Settings → Accessibility → Touch → Back Tap. Import and Back Tap assignment require user interaction.

The preset asks for amount, category, merchant, and payment wallet, then saves immediately after wallet selection, without another confirmation. Wallet names omit generated internal IDs; repeated names receive a short numbered suffix so every wallet remains selectable. It fetches only authorized active wallet labels and IDs; balances and history are never returned to the preset. A failed wallet lookup displays the server message and stops before saving. It sends an HTTPS JSON POST to the canonical Finance Tracker domain; no browser or Google credential is embedded. Only the public template is distributed. A configured shortcut contains its private expense-only key and must not be shared.

Each account has one active connection, limited to the active wallets authorized at creation, expiring after 30 days. New wallets require replacing the connection. Older connections retain their original single-wallet scope; their old presets continue working, and the new picker offers only that one authorized wallet until replaced. Replace or Disconnect revokes the old key. Keys are hashed at rest. Management requires the existing bound browser session and a same-origin custom header. A shortcut key cannot read transaction history, manage connections, select another account or an unauthorized wallet, or call cloud sync.

A request's unique ID identifies that save attempt. The expense, wallet debit, new OCC revision, and idempotency receipt are committed atomically with string CAS. A retry with the same request ID and details returns the original receipt; changed details or a changed payment wallet using that ID are rejected. Legacy single-wallet receipt fingerprints remain compatible. Retries read the latest cloud snapshot, preserving other writers' changes. Stale browser sync writes use the existing conflict flow. Existing expense deletion/refund uses deductedAmount.

The preset finishes quietly only when the server explicitly returns success. Rejected saves display the server message; a response without a usable success result or message displays unknown-save guidance. Cancel any entry prompt before selecting a wallet to stop without saving. Once the save request has been sent, closing a popup does not undo it. There is no offline queue or automatic claim of success. If a request is interrupted, check History before starting a NEW shortcut run; a fresh run creates a new request ID. Insufficient/missing/archived wallets do not deduct. A revoked or expired connection must be reconnected. No existing data migration or new environment secret is required.

Existing installed shortcuts do not update with a web deployment. Download and install the updated preset to get quiet saving, configure its private key, and keep Back Tap assigned to the intended working shortcut. Existing connection keys remain compatible within their original scope and expiry. Never share a configured preset.

## Rebuilding the public preset on macOS

Run `python3 scripts/build-quick-expense-shortcut.py --output /tmp/ft-quick-expense.wflow`, then `shortcuts sign --mode anyone --input /tmp/ft-quick-expense.wflow --output "public/shortcuts/Finance Tracker Quick Expense.shortcut"`. Apple's signing service receives the public template for validation. Never sign or commit a preset with a real private key. The unsigned source contains a placeholder and an import question.

Before release, import the signed artifact into Shortcuts and verify the action list, import question, amount/category/merchant/wallet prompts, immediate saving, JSON body, silent success, visible failure/unknown responses, cancellation, and interrupted-save guidance. Use only a disposable local/test connection. On the owner's iPhone after deployment, check Add Shortcut, Back Tap, per-run wallet selection, one expense and one reversal, repeat-request protection, and Disconnect. Automated tests cover account isolation, CAS conflicts, and failure paths; they do not replace native import/run validation.
